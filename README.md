# Sistema de Eventos Universitários

Este é um trabalho da faculdade. O objetivo foi criar um site simples para
mostrar os eventos de uma universidade, como palestras, minicursos, workshops
e oficinas.

## O que o site tem

- Página inicial com a lista de eventos
- Página de programação com uma tabela dos horários
- Página de inscrição com um formulário

## Como foi feito

O site foi feito só com HTML e CSS, sem usar JavaScript ou outras ferramentas
prontas.
